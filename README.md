> 🐶🐱 **MEOW & WOOF** es una plataforma e-commerce web diseñada para la compra y gestión simplificada de productos para mascotas (alimentos, juguetes y accesorios), garantizando una navegación intuitiva, roles de usuario definidos y administración de inventario.

---

## Características Principales

- **Autenticación y Roles Diferenciados:**
  - **Invitados:** Navegación por el catálogo de productos.
  - **Clientes:** Registro/Login, gestión de carrito de compras, orden de pedido (checkout) e historial de compras.
  - **Administradores:** Control total de inventario (CRUD de productos y stock) y métricas de ventas.
- **Carrito de Compras:** Añadir, modificar cantidades, eliminar productos y cálculo total en tiempo real.
- **Exploración y Filtros:** Búsqueda por categorías (*Comida, Juguetes, Accesorios, Collares/Pecheras*).
- **Dashboard Estadístico (Admin):** Visualización de métricas clave, gráficos de ingresos por categoría, órdenes nuevas y productos más vendidos.
- **Diseño e Interfaz:** Sistema responsivo con paleta de colores vibrante (naranja, amarillo y blanco) y navegación mediante carrusel interactivo.

---

## Stack Tecnológico

- **Backend:** Python / Django Web Framework
- **Frontend:** HTML5, CSS3, JavaScript (Navegación interactiva y carrusel)
- **Metodología:** Ágil (Scrum) (Proyecto universitario)
- **Herramientas DevOps & Planificación:** Git (Workflow por ramas) y Trello (Kanban)
